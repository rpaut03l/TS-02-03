# Lecture 04 — Recurrent Neural Networks

`[← Deep Learning Hub](../README.md) · [🔝 Top](#lecture-04--recurrent-neural-networks)`

**Instructor:** Dr. Anushka Joshi, IIT Jodhpur | **Date:** April 2026 | **Source slides:** "Recurrent Neural Networks" deck, parts 1 & 2 (combined)
