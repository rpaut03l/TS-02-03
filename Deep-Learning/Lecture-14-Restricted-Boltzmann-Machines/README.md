# Lecture 14 (Bonus) — Restricted Boltzmann Machines

`[← Deep Learning Hub](../README.md) · [🔝 Top](#lecture-14-bonus--restricted-boltzmann-machines)`

> ⚠️ **Bonus lecture — not part of the original 541-page slide deck.** RBMs and Deep Belief Networks aren't mentioned anywhere in the source material. Built to complete the historical picture connecting to Lecture 12's mention of Hinton's 2006 breakthrough.

Covers energy-based models, the Boltzmann distribution, why "restricted" (bipartite structure) matters, the RBM energy function, hidden/visible activation formulas, Gibbs sampling, Contrastive Divergence training, Deep Belief Networks, and RBM's place in deep learning history.
